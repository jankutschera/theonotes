# Example reference: restart the home router

#getting started#

1. Unplug the power cable.
2. Wait 30 seconds.
3. Plug it back in and wait until the main light is steady.
4. Check one device, then the rest.

Still down after five minutes? Look at the cable from the wall first. A reference is a note you come back to, so keep it short and exact. Copy this note to try the pattern; the kinds are explained in [[Ideas, Logs and References]].
