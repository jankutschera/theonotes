# Import, export and back up

#getting started#

Your notes are plain text, so they move in and out easily.

## Bring your notes in

Choose **File ▸ Import Notes…** and pick files or folders: Markdown, text, HTML, RTF, TextBundle and more. For notes from other apps, use **File ▸ Import From**:

- **Import From ▸ Bear…** brings a library over from Bear
- **Apple Notes…** reads the Notes app directly. macOS asks you for permission first
- **Apple Notes Export…** takes the folder you saved from Notes with File ▸ Export as ▸ Markdown
- **Evernote…** takes the export files (.enex) that Evernote writes
- **Notion…** takes the zip file from Notion's workspace export, or the folder you unpacked it into

The import window shows what it found and what it did. Titles, dates and tags come along where the other app has them.

## Take your notes out

Choose **File ▸ Export Notes…** to save the selected notes, or a whole tag, as Markdown, TextBundle, plain text, HTML, PDF or Rich Text. Pictures and files go with them. Settings ▸ General decides whether tags are kept in exported files.

To share a single note, **Edit ▸ Copy As** copies it as Markdown, HTML or rich text, and **File ▸ Print…** prints it.

## Back up

Choose **File ▸ Backup Notes…** to save everything in one file: notes, pictures, files, tags and pins. Locked notes stay locked inside it.

**File ▸ Restore Backup…** reads such a file back. Merge adds what is missing and keeps what you have. Replace All swaps your library for the backup, and asks you first. Before it does, it saves a safety copy of your current notes.

Theo Notes also keeps a daily copy of the database. Settings ▸ Advanced shows when the last one was made and where the folder is.
