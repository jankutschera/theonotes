# Tags and links

#getting started#

There are no folders in Theo Notes. You sort notes with tags, and you connect them with links.

## Tags

Type `#` and a word anywhere in a note, like `#recipes`, and the note has that tag. Every tag shows up in the sidebar. Click one to see its notes.

- A tag with spaces ends with another hash: `#book club#`
- A slash nests a tag inside another: `#work/clients/acme`. The sidebar shows a tree, and a parent tag also covers everything below it
- Typing `#` suggests the tags you already use
- Drag a note onto a tag in the sidebar to give it that tag
- Right-click a tag to rename it, change its icon or pin it. Renaming a tag updates every note that uses it

Look at the sidebar: this note has the tag `getting started`, and so do the other notes of this tour.

## Links between notes

Put a title between double square brackets to link to another note. `[[Welcome to Theo Notes]]` becomes this link: [[Welcome to Theo Notes]]. Click it to open the note, or Command-click to open it in a new window.

- Type `[[` and pick a note from the suggestions
- Add a slash to link to a heading inside a note: `[[Write and format/Lists and to-dos]]`
- Add a bar to show other words: `[[Find anything|how to search]]` shows as [[Find anything|how to search]]
- Leave the title out to link to a heading in the same note: `[[/Tags]]`

## See who links here

Open the Info panel with the ⓘ button in the toolbar and choose Backlinks. It lists the notes that link here, and the notes that mention this title without a link yet, with a button that turns the mention into a link.

If you change the title of a note, the links that point to it are updated for you.
