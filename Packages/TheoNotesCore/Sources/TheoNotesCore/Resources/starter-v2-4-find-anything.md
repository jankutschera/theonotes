# Find anything

#getting started#

You want to find a note again in seconds, even one you wrote months ago. This note shows how, from the fastest way to the most exact.

## Jump to a note by its title

On the Mac press ⌘O for Quick Open. On iPhone and iPad tap the magnifier button at the bottom of the note list. Type a few letters of a title. Open the note with Return on the Mac, or by tapping it on iPhone and iPad. On the Mac, Command-Return opens it in a new window. Start with `#` to look for a tag, or with `@` to jump to a place in the sidebar.

## Search every note

Type in the search box above the note list. The list narrows down as you type.

- Several words find notes that contain all of them
- Put a phrase in quotes to find those words together: `"weekly review"`
- Use `or` to accept either word: `tea or coffee`
- Put a minus in front of a word to leave it out: `meeting -draft`
- Add a tag to look inside it: `#recipes pasta`. Use `-#recipes` to leave a tag out
- Add `@title` to look at titles only: `@title meeting`

## Special searches

Words that start with `@` search for kinds of notes.

| Type | Finds |
|---|---|
| `@today` | notes you changed today |
| `@last7days` | notes you changed this week |
| `@todo` | notes with to-dos still open |
| `@done` | notes whose to-dos are all done |
| `@untagged` | notes without a tag |
| `@pinned` | pinned notes |
| `@images` | notes with pictures |
| `@files` | notes with attached files |
| `@code` | notes with code |
| `@locked` | locked notes |
| `@wikilinks` | notes that link to other notes |

The sidebar has some of the same places ready to tap or click: To Do, Today, Untagged and Locked.

## Find inside one note

On the Mac press ⌘F while you are in a note. On iPhone and iPad tap Note Actions and choose Find in Note, or More ▸ Find and Replace. Matches are highlighted, and you can replace them too.
