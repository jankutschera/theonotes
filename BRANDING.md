# Branding

The name "Theo Notes", the Theo logo and the app icon are not licensed under the GNU General Public License. The GPL applies to the source code only. How the name may be used is described in [TRADEMARK.md](TRADEMARK.md).

If you build and distribute your own version:

- Pick a different product name and replace the icon. The repository is meant to ship a neutral placeholder icon set for forks; the official icon is part of the release build only.
- Change the bundle identifiers and the team: `config/identity.env` holds the bundle root and `config/release.env` holds the Apple team and signing profile names.
- Do not present your version as the official app or as endorsed by the Theo Notes project.

You may say that your work is based on, or compatible with, Theo Notes.
