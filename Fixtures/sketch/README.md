# PencilKit transport fixture

`one-stroke.drawing` is a test-only `PKDrawing.dataRepresentation()` created on macOS 27.2 / Xcode 27.2. It contains a single blue pen stroke through three synthetic points: (8,12), (36,42), and (80,24), with a fixed creation date and random seed. It contains no user drawing data.

`one-stroke.png` is that drawing rendered with PencilKit and ImageIO to a 96 × 64 PNG, with the drawing bytes in a private ancillary `thND` chunk. The chunk payload is `TNPK`, version byte `1`, and the exact `.drawing` bytes; the chunk CRC covers its type and payload. The chunk is unsafe to copy when an image is modified, so an image editor that does not understand it must drop it rather than leave stale drawing data.

- PNG SHA-256: `b230e42019b40ffab7c458df722d7f01dc16da14ff8fd17afc84264ef83525bb`
- Drawing SHA-256: `b172499f03a8d92c254fea9197f6506d4a7de91dc130bee96fafe674ab9245bf`

Tests compare this fixed fixture and decode it on the destination runtime; they do not assume PencilKit or ImageIO will generate identical bytes on other OS versions.

`conflict-left.*` and `conflict-right.*` were generated by the iOS 27.0 simulator from two independently offset PencilKit strokes. Each PNG renders its corresponding changed drawing and stores its exact archive in `thND`; both drawing archives and both images differ from the baseline and from one another.
