# Backup fixtures

`v1-minimal.baerchen-backup` is a version 1 `.baerchen-backup` archive (manifest `version` 1,
`library.json` `version` 1, no focus-state fields).

- **Source:** generated by this repository's own `LibraryBackup.create` at commit `a8559348`,
  before backup format v2 existed, from a temporary library. No third-party app data, no real library.
- **Content:** two notes created at fixed times. `# Plain note` (`fixture-plain-body`, one open
  to-do) and `# Locked note` (`fixture-locked-body`), locked with the password
  `fixture-password`. Note ids are random UUIDv7 values; tests look notes up by title.
- **Author / licence:** Theo Notes project, same licence as the repository. The password is a
  public test value.
- **Used by:** `LibraryBackupTests.v1ArchiveStillRestores`. It must never be regenerated with
  newer code: its value is that an older build wrote it.
